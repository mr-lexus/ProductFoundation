Проект следует [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/)

## Ещё не выпущено

### Изменено

- README теперь объясняет системные инварианты, ответственность общего фронтенда,
  RPC на основе контрактов, проверяемую архитектуру, ограничения работы с ИИ
  и компромиссы жизненного цикла снимка шаблона.
- Добавлены короткий маршрут знакомства, ссылки по всему примеру надёжной
  операции и требования к подтверждениям будущих изменений основы из опыта продуктов.
- Все страницы документации доступны на русском и английском с переключением
  на перевод той же страницы и навигацией внутри выбранного языка.
  `check:docs` проверяет полноту пар и согласованность ссылок.

### Исправлено

- Проверка FSD разрешает обычные псевдонимы и импорты собственного пакета,
  запрещает псевдонимы путей TypeScript в общем фронтенде, которые могли бы
  расходиться с проверкой, и покрыта регрессионными тестами.

## [0.1.0-beta.1] — 2026-07-18

### Добавлено

- Исполняемый пример надёжной мутации с проверками HTTP, PostgreSQL,
  фонового процесса и Compose.
- Обязательные проверки чистоты репозитория, нативной безопасности,
  границ импортов через AST и интеграционные тесты.
- Просмотр сообщений с исчерпанными попытками и подтверждённый повтор
  одного сообщения.

### Изменено

- Конкурентная идемпотентность использует рекомендательную блокировку
  на время транзакции и хранит только завершённые результаты.
- Завершение и ошибка outbox защищены отдельным токеном захвата
  с ограниченным сроком.
- Публичный статус явно обозначен как бета до подтверждения полного
  успешного набора приёмочных проверок в открытом доступе.
- Основа распространяется как версионированный снимок шаблона
  без автоматических обновлений.
- До первой публичной беты из `@product-foundation/backend-core` удалены
  неиспользуемые заготовки экспортов аудита, трассировки и воспроизводимых проекций.

### Безопасность

- Строгая проверка JSON media type и ключа идемпотентности.
- Точные нативные origin и закреплённые digest базовых образов контейнеров.
- Сообщения outbox отклоняют значения, которые нельзя надёжно сохранить
  как JSON, до выполнения SQL.

### Проверка

- `pnpm check`, рабочая сборка, smoke-тест скомпилированного API,
  сборка Mobile, проверка нативной безопасности и изолированный запуск
  `dev:demo` из чистой копии прошли локально 2026-07-18.
- PostgreSQL/Compose, переименование продукта, отладочная сборка Android,
  Rust format/clippy и сборка Tauri прошли для кандидата `a7f90a9`
  в [запуске CI 29644574960].
- Проверка зависимостей приватного репозитория выполнила аудит всего lockfile
  на уязвимости высокой серьёзности; известных уязвимостей не найдено.
  Проверка доступности CodeQL прошла отдельно в [запуске 29644574964].
  Загрузка CodeQL и проверка изменённых зависимостей GitHub включаются
  автоматически для публичного репозитория.
- Аннотированный тег публикуется только после прохождения тех же обязательных
  проверок последним коммитом документации в [PR #6].
