# Оболочка Web

[English version](./AGENTS.md)

Эта оболочка отвечает за запуск браузерного приложения, конфигурацию PWA
и интерфейс обновления. Импортируйте интерфейс продукта через
`@app/frontend-app`; функции продукта здесь не размещаются.
Платформа задаётся литералом, а не переменной окружения сборки.

Результат — `apps/web/dist`. Только эта оболочка может импортировать
PWA/Workbox и регистрировать service worker. Кешируйте только статические
ресурсы приложения. Подстановка SPA применяется к переходам между документами,
исключая ресурсы и сервисные адреса основы. Работа продуктовых данных
без сети требует собственных требований.

После изменения PWA выполните проверку типов Web, проверку результатов сборки
и `pnpm --filter @app/web test:pwa`. Инициализируйте имя и идентификаторы
через `product:rename`; манифест Web не задаёт идентичность других платформ.
