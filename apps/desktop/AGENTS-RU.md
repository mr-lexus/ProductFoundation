# Оболочка Tauri

[English version](./AGENTS.md)

Эта оболочка владеет своей точкой входа Vite, запуском Rust, CSP и адаптерами
настольной платформы. Интерфейс продукта приходит из `@app/frontend-app`.
Никогда не импортируйте другую оболочку приложения.
Результат — `apps/desktop/dist`; Tauri упаковывает только этот каталог.
Ресурсы PWA и регистрация service worker запрещены.

Задавайте origin API явно и формируйте CSP из того же проверенного origin,
который использует фронтенд. Сохраняйте преобразование пользовательского
протокола в HTTP для Windows и пользовательские origin macOS/Linux,
если одновременно не меняются тесты и документированные списки разрешений.

`check` остаётся проверкой Cargo, `dev` и `build` — командами Tauri.
Для работы только с фронтендом используйте `check:frontend`,
`dev:frontend` и `build:runtime`.
После изменения нативной конфигурации запускайте `pnpm check:native`.
