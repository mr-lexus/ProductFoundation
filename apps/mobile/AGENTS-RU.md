# Оболочка Capacitor

[English version](./AGENTS.md)

Эта оболочка владеет своей точкой входа Vite, конфигурацией Capacitor
и нативными адаптерами. Интерфейс продукта приходит из `@app/frontend-app`.
Никогда не импортируйте другую оболочку приложения.
Результат — `apps/mobile/dist`; Capacitor упаковывает только этот каталог.
Ресурсы PWA и регистрация service worker запрещены.

Задавайте origin API явно; рабочие сборки и CI требуют HTTPS.
Live reload доступен только через явный локальный режим разработки.
Сохраняйте точные origin упакованных приложений, если одновременно
не меняются списки разрешений API, тесты и документация.

`check` остаётся проверкой типов конфигурации Capacitor;
`check:frontend` проверяет фронтенд. Для изменений нативной конфигурации
запускайте `pnpm check:native`. Инициализируйте имя и идентификаторы продукта
до генерации игнорируемых Git проектов Android/iOS.
