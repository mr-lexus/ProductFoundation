# Правила разработки с ИИ — Backend Core

[English version](./AGENTS.md)

`@product-foundation/backend-core` содержит только прикладные интерфейсы
без привязки к фреймворку, общую область и область арендатора, координацию
надёжного выполнения и общие серверные типы.

Нельзя импортировать NestJS, Fastify, драйверы PostgreSQL, SDK метрик, React
и пакеты продукта. Не добавляйте сущности, права или сценарии продукта.
Внешние действия описываются интерфейсами, реализации которых передаёт
точка сборки приложения.

Предпочитайте небольшие явные интерфейсы универсальным репозиториям
и локаторам сервисов. Изменение должно быть применимо хотя бы к двум
несвязанным предметным областям и проверяться тестом пакета или потребителя.

Идемпотентная мутация атомарна с предоставленной SQL-транзакцией.
Проверенное состояние, outbox и завершение журнала фиксируются вместе;
внешние действия принадлежат идемпотентным обработчикам outbox.
