# Правила разработки с ИИ — Backend PostgreSQL

[English version](./AGENTS.md)

`@product-foundation/backend-postgres` реализует интерфейсы backend-core
через `pg` и владеет SQL-миграциями основы.

Разрешены:

- жизненный цикл пула и механизм транзакций;
- необязательный контекст транзакции арендатора;
- хранение идемпотентности и outbox;
- просмотр outbox и очистка по срокам хранения;
- исполнитель миграций и нейтральные таблицы основы.

Таблицы продукта, принадлежащие арендаторам, должны включать и принудительно
применять PostgreSQL RLS, иметь явную политику на основе транзакционного
`app.tenant_id` и регистрироваться при запуске или в тестах продукта
через `assertTenantRelationsSecure`.

Запрещены:

- таблицы и понятия предметной области продукта;
- сборка приложения NestJS/Fastify;
- решения об авторизации;
- изменение уже применённой миграции.

Истории миграций разделены пространствами имён. Файлы основы используют
`foundation`; каждый продукт — своё постоянное пространство имён.
Интеграционные тесты выполняются с настоящим PostgreSQL.
