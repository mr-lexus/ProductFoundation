# Правила разработки с ИИ — RPC-сервер

[English version](./AGENTS.md)

Пакет выполняет процедуры `@product-foundation/rpc` без NestJS и Fastify.
Он отвечает за проверку границ, форматы сообщений, метаданные запроса
и идемпотентности, преобразование прикладных ошибок. Транспортные адаптеры
явно передают инициатора, сигнал отмены и структурированное логирование ошибок.
