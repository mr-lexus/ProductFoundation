# ADR 0007: Общая основа для независимых продуктов

[English version](./0007-reusable-multi-project-foundation.md)

- Статус: принято
- Дата: 2026-07-12

## Контекст

Репозиторий предназначен для копирования в несвязанные продукты. Понятия
конкретного продукта не должны проникать в общий протокол, среду выполнения,
механизмы безопасности или хранения.

## Решение

В репозитории два уровня ответственности:

- `@product-foundation/*` — переиспользуемые пакеты без привязки к продукту;
- `@app/*` — заменяемый прикладной слой.

Начальные пакеты основы:

- `rpc` — контракты протокола и форматы сообщений;
- `rpc-client` — вызов fetch, отмена и типизированные ошибки клиента;
- `rpc-server` — проверка данных и выполнение процедур без привязки к фреймворку;
- `backend-core` — прикладные интерфейсы, общая область и область арендатора,
  координация надёжного выполнения;
- `backend-postgres` — адаптеры `pg`, исполнитель миграций и миграции основы;
- `config` — общие настройки инструментов.

Пакеты основы никогда не импортируют пространство имён продукта. Продукт
владеет своими процедурами, бизнес-модулями, системой прав, миграциями,
сборкой приложения Nest, интерфейсом и конфигурацией развёртывания.

Ключ журнала миграций — `(namespace, name)`. Основа использует `foundation`;
каждый продукт выбирает своё постоянное пространство имён.

Пакеты остаются приватными, поскольку репозиторий копируется целиком.
Если команде понадобятся независимо обновляемые общие пакеты между
репозиториями, публикация и семантическое версионирование потребуют отдельного ADR.

## Последствия

Изменения основы проверяются отдельно и через `@app/*` как реального
потребителя. Настройка сборки становится немного сложнее, зато код продукта
не превращается случайно в универсальную абстракцию.
