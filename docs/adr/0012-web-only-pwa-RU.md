# ADR 0012: Жизненный цикл PWA только в Web

[English version](./0012-web-only-pwa.md)

- Статус: принято
- Дата: 2026-10-04

## Контекст

Устанавливаемому Web-приложению нужны манифест, иконки и поддерживаемый
жизненный цикл service worker. Нативные оболочки не должны упаковывать
или регистрировать его. Правила работы продуктовых данных без сети пока неизвестны.

## Решение

- Web использует vite-plugin-pwa generateSW и явную регистрацию
  с предложением обновления пользователю.
- Кешируются только оболочка приложения и статические ресурсы.
  Кеша API, очереди мутаций, репликации и разрешения конфликтов нет.
- Workbox NavigationRoute ограничивает подстановку запросами навигации.
  Документы SPA в области действия получают index.html; URL ресурсов
  и существующие пути rpc/health/metrics исключены. Соглашение `/api`
  этим не вводится.
- Обновление предлагает «Перезагрузить / Позже». Собственного ежечасного
  опроса или опроса при возврате на страницу нет.
- В разработке worker не регистрируется. Нативные точки входа не импортируют PWA.
- product:rename обновляет платформенные значения-заготовки, включая имя
  и короткое имя манифеста Web. Метаданные Web не задают идентичность других платформ.
- Обязательные браузерные тесты проверяют регистрацию, навигацию по оболочке
  без сети и отсутствие кеширования API. Сквозной тест обновления между
  двумя сборками необязателен, пока не доказана его стабильность.

## Последствия

Web получает сохраняемую клиентскую оболочку и требования к кешированию
при развёртывании. Интерфейс установки зависит от браузера. Данные продукта
требуют сети; подпись выпусков и обновление нативных приложений остаются
отдельными задачами продукта.

Web напрямую объявляет зависимость `workbox-window`: изолированное разрешение
пакетов pnpm не находило импорт виртуального модуля регистрации только через
транзитивные зависимости плагина. `vite-plugin-pwa` и Playwright нужны
для разработки, а `workbox-window` обеспечивает регистрацию в браузере.
