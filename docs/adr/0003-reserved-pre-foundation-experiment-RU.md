# ADR 0003: Зарезервированный номер раннего эксперимента с бэкендом

[English version](./0003-reserved-pre-foundation-experiment.md)

- Статус: заменено до публичной бета-версии
- Дата: 2026-07-11

Этот номер принадлежал эксперименту с бэкендом конкретного продукта. Эксперимент
удалили, когда репозиторий стал нейтральной технической основой. Номер остаётся
зарезервированным, чтобы не переиспользовать исторические ссылки и не менять
нумерацию последующих ADR.

Текущее решение о серверной среде описано в [ADR 0004](./0004-nestjs-fastify-RU.md).
