# Границы основы и продукта

[English version](./foundation-boundaries.md)

В репозитории два уровня ответственности.

## `@product-foundation/*`

Техническое ядро не содержит предметную область продукта:

| Пакет | Ответственность |
| --- | --- |
| `rpc` | Протокол, форматы сообщений, ошибки, описание процедур |
| `rpc-client` | Вызов fetch, отмена запросов, проверка ответов |
| `rpc-server` | Проверка входа и выхода, выполнение обработчиков |
| `backend-core` | Интерфейсы авторизации и области данных, координация идемпотентности и outbox |
| `backend-postgres` | Адаптеры `pg` и миграции основы |
| `config` | Общие настройки инструментов |

Пакеты основы не импортируют `@app/*`, React, код сборки приложения NestJS
и контракты продукта. Прямой импорт `pg` разрешён только в `backend-postgres`.

## `@app/*`

Заменяемый слой продукта отвечает за:

- публичные контракты продукта;
- серверные функциональные модули и сборку приложения NestJS;
- общий фронтенд и платформенные оболочки;
- миграции продукта и систему прав;
- конфигурацию развёртывания и метки для наблюдаемости.

Зависимости направлены только от `@app/*` к `@product-foundation/*`.

Пакеты остаются приватными внутри рабочего пространства. Шаблон копируется
целиком, поэтому реестр, публикация и отдельное версионирование пакетов не нужны.
